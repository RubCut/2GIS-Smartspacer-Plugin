# ETA до адреса — плагин для Smartspacer (2ГИС)

Добавляет в Smartspacer три Complication (маленькие иконки рядом с основной карточкой):
время в пути до заданного адреса на машине, пешком и на общественном транспорте.
Считает через публичные cloud-эндпоинты Routing API и Geocoder API 2ГИС.

## Как это устроено

- `SettingsActivity` — экран настроек: сюда вводится API-ключ 2ГИС и адрес назначения.
  При сохранении адрес геокодируется в координаты через Geocoder API и сохраняется.
- `EtaComplicationUpdateReceiver` — получает от Smartspacer периодический broadcast
  (раз в 15 минут, см. `Constants.REFRESH_PERIOD_MINUTES`), берёт последнюю известную
  геолокацию телефона, дёргает Routing API 2ГИС для всех трёх режимов передвижения
  и кладёт результат в SharedPreferences.
- `CarEtaComplication` / `WalkEtaComplication` / `TransitEtaComplication` — сами
  Complication-провайдеры. Они **не** ходят в сеть — просто быстро читают
  закэшированное значение (так требует SDK Smartspacer: `getSmartspaceActions()`
  не должен блокироваться на сетевых запросах).

## Что нужно сделать перед сборкой

### 1. Получить ключ 2ГИС

1. Зарегистрируйся в [Platform Manager 2ГИС](https://platform.2gis.ru/).
2. Создай демо-ключ / оформи тариф с доступом к **Routing API** (маршруты
   для авто/пешком, `/routing/7.0.0/global`), **Public Transport API**
   (`/public_transport/2.0`) и **Geocoder API** (`/3.0/items/geocode`).
3. Проверь квоты и условия использования именно для того сценария, который тебе
   нужен (личный проект / коммерческое приложение) — у 2ГИС отдельные тарифы
   на каждый продукт.

> ⚠️ Перед тем как встраивать ключ в приложение, обязательно проверь запросы
> вручную через `curl` (примеры есть в [документации 2ГИС](https://docs.2gis.com/ru/api/navigation/overview)),
> особенно ответ `/public_transport/2.0` — его точную схему стоит свериться
> с актуальным API Reference. В коде `TwoGisClient.kt` разбор ответа сделан
> отказоустойчиво (ищет поле `total_duration` в любом месте JSON), но если
> 2ГИС поменяет структуру ответа, лучше подстраховаться и свериться самому.

### 2. Проверить applicationId

Package name в проекте — `com.rubcut.gis2smartspacer`. Можешь оставить
как есть или поменять — тогда не забудь поправить:
- `applicationId` и `namespace` в `app/build.gradle.kts`
- authorities в `AndroidManifest.xml` (они собираются автоматически через
  `${applicationId}`, менять не нужно)
- значения `AUTHORITY_*` в `Constants.kt` — **должны совпадать** с тем, что
  соберётся в манифесте (applicationId + `.complication.car/walk/transit`)

### 3. Собрать APK

Открой проект в Android Studio (или `./gradlew assembleDebug` из терминала
с установленным Android SDK) и собери обычный debug/release APK.

### 4. Установить и настроить

1. Установи собранный APK на телефон вместе со Smartspacer.
2. Открой приложение "ETA до адреса", вставь ключ 2ГИС и адрес назначения,
   нажми "Разрешить доступ к геолокации", затем "Сохранить".
3. В Smartspacer добавь три Complication из этого приложения (Car / Walk /
   Transit ETA) к любому Target.

## Важные нюансы

- **Стоимость.** Routing/Public Transport/Geocoder API 2ГИС — платные продукты
  с квотами. Обновление раз в 15 минут = до ~96 обновлений/сутки на каждый из
  3 режимов = почти 300 запросов в день. Подбери период (`REFRESH_PERIOD_MINUTES`)
  и набор режимов (можно удалить ненужные Complication из манифеста) под свой тариф.
- **Геолокация.** Плагин использует `LocationManager.getLastKnownLocation()` —
  то есть последнюю точку, которую уже знает система (не запрашивает активное
  слежение). Это экономит батарею, но если телефон долго не определял позицию
  (например, лежал без сети/GPS), координаты могут быть устаревшими.
- **Формат Complication.** Текст в Basic Complication ограничен 12 символами —
  поэтому выводится короткий формат вроде "23 мин" или "1 ч 5 м".
- **12 символов и мультипликация ошибок.** Если геокодирование или маршрут не
  получилось построить, Complication просто не показывается (пустой список),
  а не показывает ошибку — это соответствует рекомендациям Smartspacer SDK.

## Возможные доработки

- Кэшировать `destLat/destLon` не только по сохранению адреса, но геокодировать
  через reverse-geocoding обратно для проверки, что адрес распознан верно.
- Добавить configActivity с выбором периода обновления и лимитом "не обновлять
  ночью" для экономии квоты.
- Реализовать `createBackup`/`restoreBackup` (см. wiki Smartspacer) — сейчас не
  реализовано, поэтому при восстановлении бэкапа Smartspacer предложит настроить
  Complication заново.
